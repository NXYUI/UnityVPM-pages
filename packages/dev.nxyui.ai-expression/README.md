# AI Expression (AI 표정)

[← NXYUI Avatar Tools](../../README.md)

원하는 표정을 말로 적으면 Claude가 얼굴 쉐이프키 값을 정해 주는 Unity 에디터 도구입니다.
이 창에서 Claude API로 바로 물을 수도 있고, Claude Code 같은 MCP 클라이언트에서 아바타 표정을 고치게 할 수도 있습니다.

## 요구 사항

- Unity 2022.3, VRChat SDK - Avatars 3.10.6 이상, NDMF 1.14.8 이상
- Claude API로 쓸 때: Anthropic API 키 (사용한 만큼 요금이 듭니다)
- MCP로 쓸 때: Claude Code 등 MCP 클라이언트 (API 키는 필요 없습니다)

## 어떻게 동작하나요

1. **얼굴 사전**: 아바타마다 한 번, 얼굴 쉐이프키가 어디를(눈, 눈썹, 입, 볼 등, 왼쪽/오른쪽) 어느 쪽으로 얼마나 움직이는지 정점 이동으로 읽어 둡니다. 비짐(립싱크), 아무것도 움직이지 않는 키, 얼굴 밖의 키(바디 줄이기 등)는 뺍니다.
2. Claude는 이 사전을 보고 **쉐이프키 번호와 값**만 답합니다. 쉐이프키를 하나씩 만져 보지 않으니 토큰이 적게 듭니다. 사전은 프롬프트 캐시에 남아, 같은 아바타로 이어서 물으면 입력 대부분이 싸게 처리됩니다.
3. **작업본**: 기본으로 얼굴 메시의 EditorOnly 복제본에서 작업합니다. 원본은 Scene 뷰에서만 숨겨지고 값이 바뀌지 않습니다. Claude가 고친 것은 한 번에 하나씩 실행 취소(Ctrl+Z)할 수 있습니다.
4. 마음에 들면 **표정 클립으로 저장**합니다. 기본 표정과 달라진 쉐이프키만 원본 메시 경로로 담은 애니메이션 클립이 `Assets/NXYUI/AI Expression/<아바타>/`에 생깁니다. FX나 Gesture 레이어에 넣어 쓰세요.

## 시작하기

1. 상단 메뉴 **NXYUI › AI Expression**을 엽니다.
2. ‘아바타’ 칸에 씬의 아바타를 넣고 **사전 만들기**를 누릅니다.
3. 오른쪽에서 Claude API나 MCP 중 하나로 표정을 만듭니다.
4. 왼쪽 아래에서 이름을 넣고 **저장**을 누릅니다. 끝나면 **버리고 끝내기**(작업본만 지움)나 **원본에 반영하고 끝내기**를 누릅니다.

## Claude API

- **API 키**를 넣고 저장합니다. 키는 이 컴퓨터의 Unity 설정(EditorPrefs)에 암호화 없이 저장되고, 프로젝트에는 들어가지 않습니다.
- **목록**을 누르면 그 키로 쓸 수 있는 모델을 불러옵니다.
- **가볍게**: 한 번의 요청으로 번호와 값을 받습니다. 토큰이 가장 적게 듭니다.
- **직접 편집**: Claude가 값을 바꾸고, 얼굴을 찍어 보고, 다시 고칩니다. 이미지를 볼 수 있는 모델만 목록에 나옵니다. **최대 반복**과 **최대 토큰**에 닿으면 멈추고, **멈추기**로 언제든 멈출 수 있습니다.
- 요청마다 쓴 토큰(입력, 캐시 읽기·쓰기, 출력)과 이번 세션 합계가 나옵니다.
- Claude가 요청을 거절하면 그 이유 분류를 알려 줍니다. 일부 최신 모델은 거절할 때 같은 요청을 다른 모델로 넘기는 기능을 켜 두었습니다.

## MCP (Claude Code에서)

1. 오른쪽 **MCP (Claude Code)** 탭에서 **MCP 서버 켜기**를 켭니다.
2. 나오는 명령을 터미널에서 한 번 실행합니다(포트를 바꿨다면 그 포트로 나옵니다).

   ```bash
   claude mcp add --transport http nxyui-ai-expression http://127.0.0.1:38380/mcp --header "Authorization: Bearer <토큰>"
   ```

3. Claude Code에 "아바타를 수줍게 웃는 표정으로 만들어 줘"처럼 말하면, 사전을 읽고 쉐이프키를 바꾸고 얼굴을 찍어 보며 고칩니다.

MCP 도구: `get_face_dictionary`, `get_current_values`, `set_shapekeys`, `capture_face`, `reset_face`, `save_expression`.
서버는 이 컴퓨터(127.0.0.1)에서만 연결되고, 창의 명령에 든 토큰이 있어야 요청을 받습니다(다른 프로그램이나 사이트에서 온 요청은 거절). 명령을 남에게 보여 줬다면 **토큰 새로 만들기**를 누르고 다시 추가하세요. 토큰은 Unity 설정에 저장되므로, 같은 Windows 계정으로 실행되는 프로그램까지 막지는 못합니다(그런 프로그램은 프로젝트 파일도 직접 고칠 수 있습니다). 창에서 끄면 닫힙니다.

## 알아 둘 것

- **쉐이프키 이름도 보내기**(기본 켜짐): 이름을 함께 보내면 토큰은 조금 더 들지만(캐시로 대부분 아낍니다) 훨씬 정확해집니다. 끄면 번호와 움직임만 보냅니다.
- 사전은 메시의 정점 이동으로 만든 추정입니다. 눈 위치는 아바타의 눈 본(없으면 View Position)을 기준으로 잽니다.
- 편집기를 다시 켜서 작업본이 남아 있으면 창 위에 **정리** 버튼이 나옵니다. 작업본은 EditorOnly라 업로드에 들어가지 않습니다.
