# Personal Pose Deck

[← NXYUI Avatar Tools](../../README.md)

**GoGoLoco All (Modular Avatar) 1.8.6**의 포즈 메뉴에 원하는 Humanoid 포즈 클립을 넣어 나만의 포즈 덱을 만드는 Unity 에디터 도구입니다.
포즈 클립을 썸네일로 탐색하고, 게임과 같은 높이·조명으로 미리 본 뒤 덱에 추가합니다.

이 패키지에는 다른 제품의 에셋이 들어 있지 않습니다.

## 요구 사항

- Unity 2022.3, VRChat SDK - Avatars, Modular Avatar
- GoGoLoco All (Modular Avatar) 1.8.6 — 프로젝트에 따로 임포트되어 있어야 합니다.

## 시작하기

1. Edit Mode에서 아바타를 선택하고 상단 메뉴 **NXYUI › Personal Pose Deck**을 엽니다.
2. 적용 방식을 고르고, 새 프리셋을 Assets에 저장하거나 기존 프리셋을 엽니다.
   - **기존 GoGoLoco에 적용**: 아바타에 이미 달린 GoGoLoco 오브젝트를 고릅니다. 기존 Action이나 AFK 개조는 유지됩니다.
   - **아바타에 새로 적용**: 아바타 루트를 고르면 프로젝트의 GoGoLoco 프리팹을 찾아 아바타 아래에 배치합니다.
3. 왼쪽 갤러리에서 포즈를 고르거나 ‘포즈 추가’로 클립을 넣습니다. 메뉴 이름을 비우면 클립 이름을 씁니다.
4. ‘슬롯 확인’으로 원본 높이가 유지되는 포즈 수와 커스텀 슬롯 수를 확인하고 **생성 및 적용**을 누릅니다.
5. 씬을 저장하고 Build & Test로 확인합니다. 새 포즈 › 높이 조절 › 초기화 › 걷기 복귀 › 원래 쓰던 AFK 순서로 시험하면 좋습니다.

포즈를 바꿀 때는 같은 프리셋을 열어 클립을 추가·교체·제거하거나 순서를 바꾼 뒤 다시 ‘생성 및 적용’을 누릅니다.

## 포즈 탐색기

- Assets와 설치된 패키지의 AnimationClip(.anim, 모델 안의 클립)을 폴더별로 보여 줍니다. 이름·경로 검색, 정규식, 폴더·Humanoid 필터를 쓸 수 있습니다.
- 아바타 필터: 파일 이름과 경로의 별칭(로마자·히라가나·가타카나·한자)으로 선택한 아바타 전용 클립과 공용 클립을 나눠 봅니다.
- 카드를 누르면 오른쪽에 큰 미리보기가 열립니다. 좌클릭 드래그 회전, 휠 확대·축소, 휠 버튼 드래그 이동, 우클릭+WASD/QE 시선 이동.
- 창 높이가 모자라면 미리보기 아래의 컨트롤(재생, 덱에 추가, 시작 높이, Deck 설정)만 스크롤되고, 미리보기는 최소 높이를 유지해 계속 보입니다.
- 재생 속도, 반복, 프레임 이동, 좌우 반전(GoGoLoco의 미러 포즈와 같은 방식), 바닥 표시, 시점 버튼을 지원합니다.
- 덱에 들어간 클립은 카드에 ‘덱’이 표시됩니다. 체크박스로 여러 클립을 골라 한 번에 추가할 수 있습니다.
- ‘추가할 때 시작 높이 지정’을 켜면, 미리보기에서 맞춘 높이 그대로 덱에 추가됩니다.

## 미리보기

- **GoGoLoco 높이**(기본 켜짐): 프로젝트의 GoGoLoco를 그대로 실행해 게임 속 위치(시작 높이 Go/Float)로 보여 줍니다. 트래킹(VR 3점·데스크톱·풀바디)에 따른 차이도 바꿔 볼 수 있습니다.
- **바닥**: 바닥에 닿음·떠 있음·바닥 아래로 들어감과 그 거리를 표시합니다. ‘바닥에 맞추기’로 메시의 가장 낮은 점이 바닥에 닿는 높이를 찾습니다.
- **조명**: VRChat과 같은 원형 메뉴로 조명 위치, 세기, 색온도, 보조광, 환경광, 프리셋을 바꿉니다.
- **LLC**: 아바타에 Light Limit Changer가 있으면 그 조절 항목이 같은 초기값과 범위로 나타납니다. 미리보기에만 적용되고 원본 머티리얼은 바뀌지 않습니다.
- **설정 유지와 프리셋**: 카메라, 재생, 바닥, 높이, 조명, LLC 설정은 다른 포즈를 골라도, 창을 닫았다 열어도 프로젝트마다 유지됩니다. 이름을 붙여 미리보기 프리셋으로 저장할 수 있습니다.
- **썸네일에도**를 켜면 높이·트래킹·조명·LLC 설정을 갤러리 썸네일에도 적용합니다.
- 미리보기는 아바타를 격리된 씬에 복제해 Modular Avatar 조립 결과로 보여 줍니다. 옷이나 헤어를 바꿨다면 ‘미리보기 갱신’을 누르세요.

## 포즈와 시작 높이

- GoGoLoco 1.8.6의 원본 포즈 클립을 넣으면 그 슬롯을 그대로 써서, 포즈별 높이와 조작 방식(버튼/다이얼)이 유지됩니다.
- 다른 클립은 커스텀 슬롯을 씁니다. GoGoLoco는 커스텀 슬롯을 서기 높이(0.25)로 시작하므로, 덱 목록에서 포즈를 골라 ‘시작 높이 직접 지정’으로 포즈마다 높이를 정할 수 있습니다(서기 0.25·의자 0.19·바닥 0.12·눕기 0.06 바로 선택).
- **커스텀 포즈와 기준 포즈**: GoGoLoco의 포즈 레이어는 Additive라서, 다른 포즈 패키지의 클립은 그대로 넣으면 게임에서 포즈가 거의 적용되지 않습니다. 생성 및 적용은 GoGoLoco 기준 포즈를 지정한 복사본을 만들어 씁니다(원본 클립은 바꾸지 않음).
- ‘분류 페이지마다 초기화·높이 조절 넣기’(기본 켜짐)로 각 분류 페이지 앞에 초기화와 높이 조절이 들어갑니다.

## 포즈 아이콘

- ‘포즈 아이콘 만들기’(기본 켜짐)를 쓰면 생성 및 적용 때 포즈마다 배경이 투명한 아이콘을 찍어 메뉴 버튼에 넣습니다. 시점(비스듬히·정면·측면)을 고를 수 있습니다.
- ‘GoGoLoco 원본 포즈는 원래 아이콘’을 켜면 원본 슬롯 포즈는 GoGoLoco 아이콘을 그대로 씁니다. 포즈마다 직접 아이콘을 넣을 수도 있습니다.

## 생성본과 정리

- 생성할 때마다 프리셋 옆에 PoseDeck_Generated 폴더가 생깁니다. ‘다시 적용하면 이전 생성본 자동 정리’(기본 켜짐)로 쓰지 않게 된 이전 폴더를 휴지통으로 옮깁니다.
- GoGoLoco 원복은 이 도구가 바꾼 Base와 MA Menu Installer 연결만 되돌립니다. 남은 폴더는 Deck 설정의 ‘안 쓰는 생성본 정리’로 정리합니다.
- 프리셋은 ‘목록’의 ‘삭제’로 휴지통에 옮길 수 있습니다. 이미 적용된 덱은 그대로 동작합니다.

## 알아 두기

- 이 도구는 GoGoLoco의 포즈 진입·해제, 높이 보정, 초기화와 파라미터를 그대로 재사용하며 새 동기화 파라미터를 만들지 않습니다. Action, AFK, FX는 건드리지 않습니다.
- 포즈를 제어하는 다른 프리팹을 함께 넣지 마세요.
- VRCFury가 설치된 프로젝트에서도 미리보기가 동작합니다.
- 미리보기가 실패하면 Unity 콘솔에 ‘[Personal Pose Deck] 미리보기 실패’와 클립 경로·오류가 남습니다. 문제를 알릴 때 함께 보내 주세요.
