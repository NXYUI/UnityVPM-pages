# Hair Gradation

[← NXYUI Avatar Tools](../../README.md)

헤어가 앞머리·옆머리·뒷머리처럼 여러 파츠로 나뉘어 있어도, 헤어 전체에 **높이에 따라 이어지는 그라데이션 하나**를 넣는 Unity 에디터 도구입니다.
그라데이션 안에만 보이는 패턴도 얹을 수 있습니다.

실제 적용은 [TexTransTool](https://ttt.rs64.net/)이 빌드할 때 합니다. 이 도구는 헤어 루트 하나만 받아 TexTransTool 구성을 대신 만들어 주고, 파츠끼리 UV가 겹치는지 확인합니다. 원본 텍스처와 머티리얼은 바뀌지 않습니다.

## 요구 사항

- Unity 2022.3, VRChat SDK - Avatars 3.10.6 이상, NDMF 1.14.8 이상
- TexTransTool 1.0.2 이상

## 시작하기

1. Hierarchy에서 헤어의 루트 오브젝트를 고르고 상단 메뉴 **NXYUI › Hair Gradation**을 누릅니다. 우클릭 메뉴 **NXYUI › Hair Gradation**이나 Add Component › NXYUI › Hair Gradation으로도 붙일 수 있습니다.
2. Inspector의 **칠할 메시**에서 리본·핀 같은 악세서리의 체크를 끕니다. 꺼진 오브젝트는 들어가지 않습니다.
3. 그라데이션 색과 범위를 정하고, 필요하면 패턴을 넣습니다.
4. **구성 만들기**를 누릅니다. 이 오브젝트 아래에 `[TTT] Hair Gradation` 오브젝트가 생깁니다.
5. Scene 뷰의 NDMF 미리보기가 켜져 있으면 결과가 바로 보입니다. 색·범위·불투명도·패턴 색은 바꾸는 즉시 반영됩니다.
6. 메시, 텍스처, 패턴 텍스처나 반복 수, 넣을 곳을 바꾸면 **구성 다시 만들기**를 누릅니다.

`[TTT] Hair Gradation` 아래 오브젝트는 이 도구가 관리합니다. 직접 고치지 말고 Inspector에서 바꿔 주세요.

## 설정

### 그라데이션

| 항목 | 설명 |
|---|---|
| 색 | 왼쪽이 시작(위), 오른쪽이 끝(아래)입니다. 알파로 서서히 나타나게 할 수 있습니다. |
| 불투명도, 섞는 방식 | 원래 텍스처 위에 얼마나, 어떻게 섞을지 정합니다(보통, 곱하기, 스크린, 오버레이 등). |
| 범위 | 헤어 맨 위(0%)부터 가장 아래 끝(100%) 중 그라데이션이 펼쳐지는 구간입니다. 범위 밖은 끝 색이 이어집니다. |

높이는 아바타 기준 위아래로 잽니다. 파츠가 나뉘어 있어도 같은 높이는 같은 색이 됩니다.

### 패턴 (선택)

- 패턴 텍스처를 앞에서 헤어 전체에 평행하게 투영합니다. **반복** 수만큼 이어 붙인 텍스처를 `Assets/NXYUI/Hair Gradation/<아바타>/`에 만듭니다.
- **그라데이션 안에만**을 켜면 그라데이션이 보이는 곳에만 패턴이 나옵니다. 이때 패턴은 그라데이션과 한 묶음이 되어, 그라데이션의 섞는 방식으로 원래 텍스처에 섞입니다. 그라데이션 없이 패턴만 넣는 기능은 아직 없습니다.
- **뒤쪽에도**를 켜면 앞에서 투영한 패턴이 뒷머리에도 들어갑니다.
- 평행 투영이라 옆머리에서는 패턴이 늘어나 보일 수 있습니다.

### 넣을 곳

| 선택 | 하는 일 |
|---|---|
| 메인 텍스처에 합치기 | 빌드할 때 메인 텍스처를 새로 만들어 바꿉니다. |
| lilToon 메인 컬러 2nd / 3rd | 메인 텍스처는 그대로 두고, 빌드할 때 lilToon의 2nd(또는 3rd) 컬러를 켜서 그라데이션을 넣습니다. 그 칸에 넣을 빈 텍스처를 `Assets/NXYUI/Hair Gradation/<아바타>/`에 만듭니다. lilToon 머티리얼만 되고, 섞는 방식은 보통·더하기·스크린·곱하기 중에서 고릅니다. |

**여백**은 UV 섬 가장자리 밖으로 칠하는 픽셀 수입니다. 파츠 이음매에 원래 색이 비치면 늘려 주세요.

## UV 겹침 확인

두 파츠가 텍스처의 같은 곳을 다른 높이에서 쓰면(좌우 대칭 파츠, 재사용한 UV 등), TexTransTool은 그 자리를 한 번만 칠하므로 한쪽 색이 어긋납니다.
**UV 겹침 확인**은 그런 곳이 있는 텍스처와 관련 파츠를 알려 줍니다. 한쪽 파츠의 머티리얼과 텍스처를 복제해서 따로 쓰면 해결됩니다.

## 알아 둘 것

- TexTransTool은 텍스처(lilToon 칸에 넣을 때는 머티리얼)를 쓰는 모든 곳에서 바꿉니다. 칠하지 않는 메시가 같은 텍스처나 머티리얼을 쓰면 그 메시에도 결과가 보입니다. 구성을 만들 때 그런 메시를 알려 주니, 따로 두려면 그 메시의 머티리얼과 텍스처를 복제해 주세요.
- 패턴을 넣거나 lilToon 칸에 넣을 때는 텍스처마다 TexTransTool 캔버스를 씁니다. 같은 텍스처에 먼저 걸린 다른 TexTransTool 효과는 덮일 수 있습니다.
- 이 컴포넌트(Hair Gradation Settings)는 업로드에 들어가지 않습니다.
