# Hair Gradation

[← NXYUI Avatar Tools](../../README.md)

헤어가 앞머리·옆머리·뒷머리처럼 여러 파츠로 나뉘어 있어도, 헤어 전체에 **높이에 따라 이어지는 그라데이션 하나**를 넣는 Unity 에디터 도구입니다.
그라데이션 안에만 보이는 패턴도 얹을 수 있습니다.

실제 적용은 [TexTransTool](https://ttt.rs64.net/)이 빌드할 때 합니다. 이 도구는 헤어 루트 하나만 받아 TexTransTool 구성을 대신 만들어 주고, 파츠끼리 UV가 겹치는지 확인합니다. 원본 텍스처와 머티리얼은 바뀌지 않습니다.

## 요구 사항

- Unity 2022.3, VRChat SDK - Avatars 3.10.6 이상, NDMF 1.14.8 이상
- TexTransTool 1.0.2 이상

## 시작하기

1. Hierarchy에서 헤어의 루트 오브젝트를 고르고 상단 메뉴 **NXYUI › Hair Gradation**을 누릅니다. 우클릭 메뉴 **NXYUI › Hair Gradation**이나 Add Component › NXYUI › Hair Gradation으로도 붙일 수 있습니다.
2. Inspector의 **칠할 메시**에서 리본·핀 같은 악세서리의 체크를 끕니다. 꺼진 오브젝트는 들어가지 않습니다.
3. 그라데이션 색과 범위를 정하고, 필요하면 패턴을 넣습니다.
4. **구성 만들기**를 누릅니다. 이 오브젝트 아래에 `[TTT] Hair Gradation` 오브젝트가 생기고, 버튼 아래에 만든 결과와 확인할 점이 나옵니다.
5. Scene 뷰의 NDMF 미리보기가 켜져 있으면 결과가 바로 보입니다. 색·범위·불투명도·패턴 색은 바꾸는 즉시 반영됩니다.
   미리보기는 상단 메뉴 **Tools › NDM Framework › Enable Previews**로 켭니다. 켜져 있는데도 바뀐 게 없으면 **Tools › NDM Framework › Configure Previews**의 TexTransTool에서 `BeforeUVModification-Phase`와 `MaterialModification-Phase`가 켜져 있는지 확인해 주세요.
6. 메시, 텍스처, 패턴 텍스처나 반복 수, 넣을 곳을 바꾸면 Inspector가 알려 줍니다. **구성 다시 만들기**를 누릅니다.
7. 그라데이션을 빼려면 **구성 지우기**를 누릅니다. 컴포넌트만 지우면 `[TTT] Hair Gradation`이 남아서 빌드에 계속 적용됩니다.
   칠할 메시의 체크를 모두 끄면 **구성 다시 만들기**는 꺼지고(이유가 버튼 아래에 나옵니다), 있던 구성은 그대로 남습니다. 구성을 지우는 것은 **구성 지우기**뿐입니다.

`[TTT] Hair Gradation` 아래 오브젝트는 이 도구가 관리합니다. 직접 고치지 말고 Inspector에서 바꿔 주세요.

### Inspector가 알려 주는 상태

| 상태 | 뜻과 할 일 |
|---|---|
| 구성이 최신이에요 | 지금 설정대로 만들어져 있습니다. 씬을 닫았다 열거나 Unity를 다시 켜도, 아바타를 복제해도 그대로입니다. |
| 메시, 텍스처, 패턴이나 넣을 곳이 바뀌었어요 | **구성 다시 만들기**를 눌러야 반영됩니다. lilToon 칸에 넣을 때는 머티리얼의 셰이더를 lilToon으로 바꾼 경우도 여기에 들어갑니다. |
| 헤어의 모양이나 위치가 달라졌어요 | 헤어 길이 블렌드셰이프를 바꾸거나 파츠를 옮기면 그라데이션 범위가 헤어와 어긋납니다. **구성 다시 만들기**로 다시 맞춥니다. |
| 구성이 쓰는 텍스처가 없어졌어요 | `Assets/NXYUI/Hair Gradation` 폴더를 지우거나 옮긴 경우입니다. **구성 다시 만들기**를 누르면 다시 만듭니다. |
| 다른 헤어의 구성과 같은 빈 텍스처에 칠하고 있어요 | lilToon 칸에 넣는 헤어를 복제한 경우입니다. 이대로면 빌드에서 한쪽 그라데이션만 남습니다. 둘 중 하나에서 **구성 다시 만들기**를 누르면 따로 칠합니다. |
| 이전 버전에서 만든 구성 | 0.1.0에서 만든 구성입니다. 컷아웃 헤어의 비치는 부분을 메울 수 있으니 **구성 다시 만들기**를 한 번 눌러 주세요. |
| 예전에 만든 구성이 남아 있어요 | 컴포넌트를 Reset 하면 만들어 둔 오브젝트와 연결이 끊깁니다. **구성 다시 만들기**가 남은 것을 지우고 새로 만듭니다. |
| 가리키는 구성이 이 오브젝트 아래에 없어요 | 다른 헤어의 설정을 붙여 넣은 경우입니다. **구성 만들기**를 누르면 이 헤어에 새로 만들고, 다른 헤어의 구성은 건드리지 않습니다. |
| 이 헤어가 꺼져 있어요 | 아래 "알아 둘 것"의 꺼 둔 헤어 항목을 봐 주세요. |

0.1.0에서는 씬을 다시 열거나 Unity를 다시 켜면 구성이 늘 "바뀌었어요"로 나오고 색·범위가 바로 반영되지 않았습니다. 지금은 그대로 이어집니다.

## 설정

### 그라데이션

| 항목 | 설명 |
|---|---|
| 색 | 왼쪽이 시작(위), 오른쪽이 끝(아래)입니다. 알파로 서서히 나타나게 할 수 있습니다. |
| 불투명도, 섞는 방식 | 원래 텍스처 위에 얼마나, 어떻게 섞을지 정합니다(보통, 곱하기, 스크린, 오버레이 등). |
| 범위 | 헤어 맨 위(0%)부터 가장 아래 끝(100%) 중 그라데이션이 펼쳐지는 구간입니다. 범위 밖은 끝 색이 이어집니다. |

높이는 아바타 기준 위아래로 잽니다. 파츠가 나뉘어 있어도 같은 높이는 같은 색이 됩니다. 헤어나 그 부모 오브젝트가 스케일 -1로 뒤집혀 있어도 그대로 위에서 아래로 들어갑니다.

메인 텍스처에 넣을 때 텍스처의 알파는 그대로 둡니다. 가닥 사이가 비치는 컷아웃 헤어나 끝이 반투명한 헤어도 비치는 부분은 그대로 비치고, 색만 바뀝니다. (0.1.0에서는 그라데이션의 알파가 텍스처에 더해져, UV 섬 안의 비치는 부분이 메워졌습니다.)

### 패턴 (선택)

- 패턴 텍스처를 앞에서 헤어 전체에 평행하게 투영합니다. **반복** 수만큼 이어 붙인 텍스처를 `Assets/NXYUI/Hair Gradation/<아바타>/`에 만듭니다.
- **반복**은 가로로 반복되는 수입니다. 세로는 패턴 이미지의 비율에 맞춰 반복되므로, 정사각형이 아닌 패턴도 찌그러지지 않습니다.
- 패턴 이미지를 같은 파일로 고쳐 저장하면 Inspector가 알려 줍니다. **구성 다시 만들기**를 눌러야 고친 패턴이 들어갑니다.
- **그라데이션 안에만**을 켜면 그라데이션이 보이는 곳에만 패턴이 나옵니다. 이때 패턴은 그라데이션과 한 묶음이 되어, 그라데이션의 섞는 방식으로 원래 텍스처에 섞입니다. 그라데이션 없이 패턴만 넣는 기능은 아직 없습니다.
- **뒤쪽에도**를 켜면 앞에서 투영한 패턴이 뒷머리에도 들어갑니다.
- 평행 투영이라 옆머리에서는 패턴이 늘어나 보일 수 있습니다.
- 헤어의 부모 중에 축마다 크기가 다른(비균일) 스케일 안에서 회전한 오브젝트가 있으면, 패턴이 조금 비스듬하게 들어갈 수 있습니다. Inspector가 알려 줍니다. 그라데이션은 이 경우에도 정확히 들어갑니다.

### 넣을 곳

| 선택 | 하는 일 |
|---|---|
| 메인 텍스처에 합치기 | 빌드할 때 메인 텍스처를 새로 만들어 바꿉니다. |
| lilToon 메인 컬러 2nd / 3rd | 메인 텍스처는 그대로 두고, 빌드할 때 lilToon의 2nd(또는 3rd) 컬러를 켜서 그라데이션을 넣습니다. 그 칸에 넣을 빈 텍스처를 `Assets/NXYUI/Hair Gradation/<아바타>/`에 만듭니다. lilToon 머티리얼만 되고, 섞는 방식은 보통·더하기·스크린·곱하기 중에서 고릅니다. |

lilToon 칸에 넣을 때 알아 둘 것:

- 빌드에서는 그 칸 전체를 그라데이션용으로 씁니다. 머티리얼이 그 칸에 이미 넣어 둔 텍스처와 설정(데칼, 각도, UV 모드, 마스크, 알파 모드, 디졸브 등)은 빌드 결과에서 보이지 않습니다. 원본 머티리얼은 바뀌지 않고, 구성을 만들 때 그런 머티리얼을 알려 줍니다. 그대로 두려면 다른 칸이나 **메인 텍스처에 합치기**를 고르세요.
- lilToonLite, FakeShadow, 젬(Gem), 퍼 전용(FurOnly) 셰이더는 2nd/3rd 컬러를 그리지 않아서 건너뛰고, 어떤 머티리얼인지 알려 줍니다. 퍼(Fur) 셰이더는 바탕에만 들어가고 털 부분에는 보이지 않습니다.
- lilToon이 아닌 머티리얼과 메인 텍스처가 없는 머티리얼(단색 헤어)은 건너뜁니다. 같은 텍스처를 쓰는 lilToon 머티리얼에는 그대로 들어갑니다.
- lilToonMulti는 그 칸이 머티리얼에서 꺼져 있어도 빌드할 때 켜서 넣습니다(원본 머티리얼은 그대로입니다). 다만 Scene 뷰의 NDMF 미리보기에는 보이지 않으니, 구성을 만들 때 그 머티리얼을 알려 줍니다.
- 다른 곳에서 고른 오버레이·색상 같은 섞는 방식은 그대로 기억해 두고, lilToon 칸에서는 보통으로 섞습니다.

**여백**은 UV 섬 가장자리 밖으로 칠하는 픽셀 수입니다. 파츠 이음매에 원래 색이 비치면 늘려 주세요.

## UV 겹침 확인

두 파츠가 텍스처의 같은 곳을 다른 높이에서 쓰면(좌우 대칭 파츠, 재사용한 UV 등), TexTransTool은 그 자리를 한 번만 칠하므로 한쪽 색이 어긋납니다.
**UV 겹침 확인**은 그런 곳이 있는 텍스처와 관련 파츠를 알려 줍니다. 한쪽 파츠의 머티리얼과 텍스처를 복제해서 따로 쓰면 해결됩니다.
그라데이션의 시작이나 끝 위아래에 걸친 파츠도 TexTransTool이 칠하는 색대로 비교합니다. (0.1.0에서는 이런 파츠의 겹침을 놓칠 수 있었습니다.)

## 알아 둘 것

- TexTransTool은 텍스처(lilToon 칸에 넣을 때는 머티리얼)를 쓰는 모든 곳에서 바꿉니다. 칠하지 않는 메시가 같은 텍스처나 머티리얼을 쓰면 그 메시에도 결과가 보입니다. 구성을 만들 때 그런 메시를 알려 주니, 따로 두려면 그 메시의 머티리얼과 텍스처를 복제해 주세요.
- 텍스처마다 TexTransTool 캔버스를 씁니다. 같은 텍스처에 먼저 걸린 다른 TexTransTool 효과는 덮일 수 있습니다.
- 기본으로 꺼 두는 헤어(메뉴로 켜는 헤어)에는 아직 쓸 수 없습니다. TexTransTool은 꺼진 오브젝트 아래의 구성을 빌드에서 건너뛰므로, 헤어를 꺼 둔 채 업로드하면 그라데이션이 들어가지 않습니다. 헤어 안에서 꺼져 있는 메시도 칠하지 않습니다.
- 그라데이션 범위는 구성을 만들 때의 헤어 모양으로 잽니다. 헤어 길이 블렌드셰이프를 바꾸거나 파츠를 옮기면 Inspector가 알려 주니 다시 만들어 주세요.
- 같은 아바타에 이름이 같은 헤어 루트가 여러 개 있어도, 순서를 바꿔도, lilToon 칸에 넣을 빈 텍스처는 헤어마다 따로 만듭니다. 헤어를 복제하면 복제본이 원본과 같은 빈 텍스처를 가리키니, Inspector가 알려 주면 **구성 다시 만들기**를 눌러 주세요.
- 이 컴포넌트(Hair Gradation Settings)는 업로드에 들어가지 않습니다. 컴포넌트를 지워도 `[TTT] Hair Gradation`은 남으니, 그라데이션을 빼려면 **구성 지우기**를 먼저 눌러 주세요.
- **구성 다시 만들기**와 **구성 지우기**는 이 도구가 만든 `[TTT] Hair Gradation`만 지웁니다. 이름만 같은, 직접 만든 오브젝트는 건드리지 않습니다.
- 프리팹 인스턴스인 헤어에서도 구성과 바로 반영되는 값이 인스턴스의 오버라이드로 남아, 씬을 저장하고 다시 열어도 그대로입니다.
- 구성을 만들 때 생기는 텍스처(`Assets/NXYUI/Hair Gradation/<아바타>/`)는 Ctrl+Z로 구성을 되돌려도 파일로 남습니다. 다음에 구성을 만들 때 다시 쓰고, 필요 없으면 폴더째 지워도 됩니다. 그 텍스처를 쓰던 구성은 Inspector가 다시 만들라고 알려 줍니다.
