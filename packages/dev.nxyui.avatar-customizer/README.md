# Avatar Customizer

[← NXYUI Avatar Tools](../../README.md)

VRChat 아바타의 Expressions 메뉴를 **빌드할 때** 정리하는 Unity 에디터 도구입니다.
메뉴 항목의 이름과 위치를 바꾸고(원본 메뉴 정리), 그 위에 자주 쓰는 항목을 모은 즐겨찾기 메뉴를 만들고,
토글·래디얼의 시작 값과 블렌드쉐이프 조절 컨트롤을 추가합니다.

아바타의 메뉴·파라미터 에셋은 바꾸지 않습니다. 모든 변경은 빌드할 때 아바타의 빌드용 사본에만 들어갑니다.
Modular Avatar, One-Click Inventory 같은 다른 도구가 빌드 중에 만드는 메뉴도, 완성된 뒤에 다루기 때문에 그대로 정리할 수 있습니다.

## 요구 사항

- Unity 2022.3, VRChat SDK - Avatars
- Modular Avatar, NDMF (VCC·ALCOM이 함께 설치합니다)

## 시작하기

1. Hierarchy에서 아바타를 선택하고 상단 메뉴 **NXYUI › Avatar Customizer**를 엽니다.
2. **빌드 메뉴 읽기**를 눌러 아바타에서 실제로 만들어지는 메뉴를 읽습니다.
   - ‘빠른 읽기’(기본 켜짐)는 메뉴가 완성되는 단계까지만 빌드해 더 빨리 읽습니다. 끄면 업로드와 같은 전체 빌드로 읽습니다.
   - ‘비교’는 두 방식을 모두 실행해 결과가 같은지 확인합니다. 다르면 이후 전체 빌드로 읽습니다.
3. **원본 메뉴 정리**(1차)에서 메뉴 자체를 정리하고, **즐겨찾기 편집**(2차)에서 바로가기 메뉴를 만듭니다.
4. **빌드 결과**에서 최종 메뉴와 경고를 확인하고, 씬을 저장한 뒤 Build & Test로 확인합니다. 따로 누를 적용 버튼은 없습니다.

설정은 아바타 루트의 Avatar Customizer 컴포넌트에 저장됩니다(씬에 저장).

## 1차: 원본 메뉴 정리

아바타의 메뉴 **원본 자체**를 고칩니다. 즐겨찾기보다 먼저 적용됩니다.
왼쪽 목록은 아바타의 도구들이 만든 그대로의 메뉴입니다.

- **새 표시 이름**: 항목의 이름을 바꿉니다. 그 항목이 보이는 모든 곳(별칭이 없는 즐겨찾기 바로가기 포함)에 반영됩니다.
- **옮길 위치**: 항목을 다른 곳으로 옮깁니다. 원래 자리에서는 사라집니다.
  - 최상위
  - 새 최상위 폴더: 이름을 정하면 그 이름의 최상위 하위 메뉴 안으로 넣습니다. 없으면 빌드 때 만듭니다. 같은 이름을 고른 항목은 한 폴더에 모입니다.
  - 빌드 메뉴의 하위 메뉴(예: 직접 만든 ‘옷장’ 폴더)
- 하위 메뉴는 안의 항목과 함께 옮겨집니다. 옮긴 뒤 빈자리는 다음 페이지 항목으로 채웁니다.
- ‘More 이름’에는 자동 페이지 버튼에 쓸 이름(예: 더 보기)을 넣을 수 있습니다.

## 2차: 즐겨찾기 편집

1차로 정리된 메뉴를 바탕으로, 원본은 그대로 둔 채 **바로가기를 모은 메뉴**를 만듭니다.

- 왼쪽 목록은 원본 메뉴 정리가 반영된 메뉴입니다. 정리 규칙을 바꾸면 다시 읽지 않아도 바로 바뀝니다.
- 위쪽 **미리보기**를 누르면 정리된 메뉴를 페이지 단위로 확인할 수 있고, 옮긴 항목에는 ‘옮김’이 붙습니다.
- ‘+ 메뉴’로 즐겨찾기 메뉴를 여러 개 만들 수 있습니다. 메뉴마다 이름, 아이콘, 설치 위치(최상위 또는 왼쪽 목록의 ‘위치’로 고른 하위 메뉴), 첫 페이지 고정을 정합니다.
- 바로가기는 원본과 같은 파라미터를 써서 어느 쪽에서 켜도 같이 움직입니다. 폴더, 순서, 별칭, 아이콘을 자유롭게 정할 수 있습니다.
- 기본값: 토글은 꺼짐/켜짐, 래디얼은 0–100%로 아바타를 처음 불러올 때의 값을 정합니다. 하위 메뉴 바로가기는 ‘안의 항목’을 펼쳐 안쪽 항목의 기본값도 정할 수 있습니다.
- 즐겨찾기 메뉴는 정리 뒤에 만들어지므로, 원본을 정리 단계에서 즐겨찾기 메뉴 안으로 옮길 수는 없습니다.

### 두 기능의 차이

| | 원본 메뉴 정리 (1차) | 즐겨찾기 편집 (2차) |
| --- | --- | --- |
| 하는 일 | 원본 항목의 이름과 위치를 바꿈 | 바로가기를 모은 새 메뉴를 만듦 |
| 원본 | 바뀜(옮기면 원래 자리에서 사라짐) | 원래 자리에 그대로 남음 |
| 꾸미기 | 이름만 바꿈, 옮긴 항목은 대상 메뉴의 끝에 붙음 | 폴더·순서·별칭·아이콘·첫 페이지 고정 |
| 쓰기 좋은 경우 | 최상위 정리, 다른 도구가 만든 메뉴를 원하는 폴더로 | 자주 쓰는 항목만 모은 내 메뉴 |

자주 쓰는 항목은 즐겨찾기에 두고, 원본은 ‘옷장’ 같은 보관 폴더로 옮기면 최상위를 깔끔하게 유지할 수 있습니다.

## 블렌드쉐이프

- ‘블렌드쉐이프’ 탭에서 Skinned Mesh Renderer의 블렌드쉐이프를 찾아 값을 바로 바꿀 수 있습니다(실행 취소 가능).
- ‘+ 래디얼’ / ‘+ 토글’로 게임 안에서 그 블렌드쉐이프를 조절하는 컨트롤을 만들면, 편집 중인 즐겨찾기 메뉴에 들어갑니다.
  블렌드쉐이프 컨트롤은 원래 메뉴에 없는 새 항목이라 즐겨찾기 메뉴에만 넣을 수 있습니다.
- 첫 컨트롤을 만들면 ‘블렌드쉐이프 초기화’ 버튼이 함께 들어갑니다. 누르면 모든 블렌드쉐이프 컨트롤이 정한 기본값으로 돌아갑니다.

## One-Click Inventory와 함께 쓰기

One-Click Inventory(OCI)는 빌드 중에 옷장 메뉴를 새로 만들고 자기 컴포넌트를 지웁니다.
Avatar Customizer는 완성된 메뉴를 다루므로 OCI 메뉴도 다른 메뉴처럼 정리할 수 있습니다.

- **OCI 메뉴를 폴더로 옮기기**: ‘빌드 메뉴 읽기’ 뒤 원본 메뉴 정리에서 OCI 메뉴(예: CustomCostume)를 고르고 ‘옮길 위치’를 정합니다.
- **자기 메뉴를 가진 아이템은 메뉴가 최상위에 따로 남습니다.** 예를 들어 의상에 MA Menu Installer와 MA Menu Item(장식 토글 등)이 들어 있으면,
  그 메뉴는 OCI 옷장과 별개로 최상위에 설치됩니다. 에셋은 그대로 두고, 원본 메뉴 정리에서 그 메뉴도 원하는 폴더로 옮기세요(추천).
- 에셋을 고쳐서라도 옷장 항목 하나로 합치고 싶다면: 아이템 자체의 MA Menu Installer와 MA Menu Item(하위 메뉴)을 지우고,
  안쪽 메뉴 항목(토글들)에 OCI의 **Inventory Menu Installer**를 붙여 ‘연결된 인벤토리’를 그 아이템으로 지정합니다.
  그러면 옷장 안의 그 아이템이 ‘활성화’ 토글과 장식 토글을 함께 가진 하위 메뉴가 됩니다. 에셋 원래 구성을 바꾸는 방법이라 나중에 되돌리기 번거롭습니다.
- **OCI의 ‘메뉴 통합’은 켜지 않는 것을 추천합니다.** 아이템에 MA Menu Item(하위 메뉴)이 있을 때 켜면 그 메뉴의 항목이 사라지고 아이템 토글이 최상위에 따로 생깁니다(시험 빌드에서 확인).
- OCI 인벤토리 오브젝트에 MA Menu Item과 MA Menu Installer를 따로 붙이면 같은 이름의 메뉴가 하나 더 생깁니다. 정리는 Avatar Customizer에서 하세요.

## 알아 두기

- 이름과 경로가 바뀌어도 항목은 메뉴 경로와 파라미터로 다시 찾습니다. 찾지 못하면 ‘⚠ 연결 필요’로 표시되고, ‘다시 연결’이나 빌드 결과의 ‘연결 확인’으로 고칠 수 있습니다.
- 빠른 읽기와 전체 빌드는 생성 에셋을 Assets 아래 임시 폴더에 두었다가 읽기가 끝나면 지웁니다.
- 저장되는(Saved) 파라미터의 기본값은 사용자가 이미 바꾼 값이 있으면 그 값이 유지됩니다.
- 열린 씬의 다른 아바타에서 설정을 ‘가져오기’로 복사할 수 있습니다.
- Avatar Menu Favorites에서 옮길 때: Avatar Customizer를 설치하면 Avatar Menu Favorites는 자동으로 제거되고, 씬의 설정 컴포넌트는 그대로 이어집니다.
